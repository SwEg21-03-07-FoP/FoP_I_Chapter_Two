Chapter 2: Basic Programming Constructors

Problem Analysis and Coding Examples

Writing code is the last step. When you analyze and design first, the code almost writes itself. Follow the same five steps every time:

1 Problem description→2 Analysis: input and output→3 Process→4 Design→5 Write the code
  • Analysis: what goes in, and what must come out?
  • Process: the list of operations that turn input into output.
  • Design: decide the variables and their types, the constants, and the exact statements for reading, calculating and printing.
  • Code: type the design. Each design step becomes a block of code. Then test.

Example 1: A shop bill with discount and VAT

1. Problem description

Write a C++ program to calculate the amount a customer must pay in a shop. The program reads the unit price, the quantity bought and the discount rate (%). Orders of more than 10 items get an extra 5% discount. VAT of 15% is added after the discount.

Quantity Formula
subtotal unitPrice × quantity
discount subtotal × (discountRate + extra) / 100
taxable subtotal − discount
VAT taxable × 0.15
total due taxable + VAT

2. Problem analysis

2.1 Input
  • Unit price
  • Quantity bought
  • Discount rate (%)
2.2 Output
  • Subtotal, discount, VAT
  • Total due (the main result)

3. Process (operations)

  • Declare variables to hold the input and the results.
  • Define the fixed values (VAT rate, bulk limit, bulk extra discount) as constants.
  • Print a prompt and read the three inputs.
  • Decide the extra discount: 5% if the quantity is more than 10, otherwise 0.
  • Calculate subtotal, discount, taxable amount, VAT and total.
  • Print the results with two decimal places.

4. Design the program

4.1 Variables: what and how?

Variable Type Why this type
unitPrice double Prices have decimals.
quantity int You buy whole items.
discountRate double May be 7.5%.
extraRate double = 0.0 Starts at 0, changed only for bulk orders.
subtotal, discount, taxable, vat, total double Money results with decimals.

4.2 Constants

const double VAT_RATE = 0.15;
const int BULK_QTY = 10;
const double BULK_EXTRA = 5.0;

4.3 Reading the input

cout << "Enter unit price, quantity and discount rate (%) separated by space: ";
cin >> unitPrice >> quantity >> discountRate;

4.4 Calculation

subtotal  = unitPrice * quantity;
extraRate = (quantity > BULK_QTY) ? BULK_EXTRA : 0.0;
discount  = subtotal * (discountRate + extraRate) / 100;
taxable   = subtotal - discount;
vat       = taxable * VAT_RATE;
total     = taxable + vat;

4.5 Printing the result

cout << fixed << setprecision(2);
cout << "Total due: " << total << endl;

5. Write the code

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    // Steps 4.1 and 4.2: constants and variables
    const double VAT_RATE = 0.15;
    const int BULK_QTY = 10;          // more than this counts as a bulk order
    const double BULK_EXTRA = 5.0;    // extra discount (%) for bulk orders
    double unitPrice, discountRate, extraRate = 0.0;
    double subtotal, discount, taxable, vat, total;
    int quantity;

    // Step 4.3: read the input
    cout << "Enter unit price, quantity and discount rate (%) separated by space: ";
    cin >> unitPrice >> quantity >> discountRate;

    // Step 4.4: calculate
    subtotal  = unitPrice * quantity;
    extraRate = (quantity > BULK_QTY) ? BULK_EXTRA : 0.0;
    discount  = subtotal * (discountRate + extraRate) / 100;
    taxable   = subtotal - discount;
    vat       = taxable * VAT_RATE;
    total     = taxable + vat;

    // Step 4.5: print the result
    cout << fixed << setprecision(2);
    cout << "Subtotal : " << subtotal << endl;
    cout << "Discount : " << discount << endl;
    cout << "VAT (15%): " << vat << endl;
    cout << "Total due: " << total << endl;
    return 0;
}

Sample run 1 (a bulk order):

Enter unit price, quantity and discount rate (%) separated by space: 100 12 10
Subtotal : 1200.00
Discount : 180.00
VAT (15%): 153.00
Total due: 1173.00

Sample run 2 (not a bulk order):

Enter unit price, quantity and discount rate (%) separated by space: 100 5 10
Subtotal : 500.00
Discount : 50.00
VAT (15%): 67.50
Total due: 517.50
Why these choices
  • The conditional operator ?: makes the “only if” decision without if. In Chapter 3 you can write the same thing with if.
  • The discount is a percentage, so divide by 100 once.
  • Constants are named, so a change in the VAT rate is made in one place.
  • Check by hand: 100 × 12 = 1200; 15% of it is 180; 1020 × 0.15 = 153; 1020 + 153 = 1173.

Example 2: Change from a cashier

1. Problem description

A cashier gives change using the fewest notes and coins of 100, 50, 10, 5 and 1 birr. Write a C++ program that reads the amount due and the amount paid (whole birr; the customer always pays enough), and prints the change and how many of each note or coin to give.

2. Problem analysis

2.1 Input
  • Amount due
  • Amount paid
2.2 Output
  • The change
  • Number of 100, 50, 10 and 5 birr notes, and 1 birr coins

3. Process (operations)

  • Declare integer variables (all amounts are whole birr).
  • Read the amount due and the amount paid.
  • Calculate the change as amount paid − amount due.
  • For each value from largest to smallest: the number = rest ÷ value (integer division), and the new rest = rest % value.
  • Print the change and the five counts.

4. Design the program

4.1 Variables

Variable Type Purpose
amountDue, amountPaid int The two inputs, whole birr.
change int amountPaid − amountDue.
rest int What is still to be given back as we go.
notes100, notes50, notes10, notes5, coins1 int How many of each.

4.2 Reading the input

cout << "Enter the amount due and the amount paid (whole birr): ";
cin >> amountDue >> amountPaid;

4.3 Calculation (/ counts, % leaves the rest)

change   = amountPaid - amountDue;
notes100 = change / 100;   rest = change % 100;
notes50  = rest / 50;      rest %= 50;
notes10  = rest / 10;      rest %= 10;
notes5   = rest / 5;       rest %= 5;
coins1   = rest;

Trace by hand for due 463, paid 1000 (change 537):

Step Count (rest ÷ value) Rest after
100 birr 537 / 100 = 5 537 % 100 = 37
50 birr 37 / 50 = 0 37 % 50 = 37
10 birr 37 / 10 = 3 37 % 10 = 7
5 birr 7 / 5 = 1 7 % 5 = 2
1 birr 2 0

5. Write the code

#include <iostream>
using namespace std;

int main() {
    // Step 4.1: variables
    int amountDue, amountPaid, change, rest;
    int notes100, notes50, notes10, notes5, coins1;

    // Step 4.2: read the input
    cout << "Enter the amount due and the amount paid (whole birr): ";
    cin >> amountDue >> amountPaid;

    // Step 4.3: calculate the change and the notes
    change   = amountPaid - amountDue;
    notes100 = change / 100;   rest = change % 100;
    notes50  = rest / 50;      rest %= 50;
    notes10  = rest / 10;      rest %= 10;
    notes5   = rest / 5;       rest %= 5;
    coins1   = rest;

    // Step 4.4: print the result
    cout << "Change: " << change << " birr" << endl;
    cout << "100 birr notes: " << notes100 << endl;
    cout << "50 birr notes : " << notes50 << endl;
    cout << "10 birr notes : " << notes10 << endl;
    cout << "5 birr notes  : " << notes5 << endl;
    cout << "1 birr coins  : " << coins1 << endl;
    return 0;
}

Sample run:

Enter the amount due and the amount paid (whole birr): 463 1000
Change: 537 birr
100 birr notes: 5
50 birr notes : 0
10 birr notes : 3
5 birr notes  : 1
1 birr coins  : 2
Why these choices
  • Everything is int. With double, % would not even compile, and decimals are not needed.
  • Integer division is the goal here: 537 / 100 must give 5, not 5.37.
  • Always go from the largest value to the smallest, so the fewest notes are used.
  • rest %= 50; is the compound form of rest = rest % 50;.
