Fundamentals of Programming I
Chapter 2: Basic Programming Constructors

Practical Quiz Tasks

Instructions
  • Work on each task in the same five steps as the examples: problem description, analysis (input and output), process, design (variables, types, constants, statements), then code.
  • For each task write: (a) the inputs and outputs, (b) the process as a numbered list, (c) a table of variables with types and the constants, and (d) the complete C++ program.
  • Use only Chapter 2 tools: input/output, variables, constants, operators, the conditional operator, casting and <iomanip>. No if and no loops.
  • Compile and run your program with the test data. Use meaningful names and comments.
Marks per task Out of
(a) and (b) Analysis: inputs, outputs, process 3
(c) Design: suitable types, constants, meaningful names 3
(d) Code: compiles, correct formulas, correct output format 4
Total per task 10

Task 1: Student course total10 marks

Write a C++ program that reads a student’s assignment, midterm and final marks (each out of 100). The course total is 20% assignment + 30% midterm + 50% final. The pass mark is 50. Print the total (one decimal place) and the word Pass or Fail. Use the conditional operator (no if).

Test data: 80, 60, 70 gives 69.0 and Pass. 40, 30, 45 gives 39.5 and Fail.

Task 2: Electricity bill10 marks

Write a C++ program that reads the electricity units (kWh, a whole number) used in a month. The first 50 units cost 1.50 birr each and every unit above 50 costs 2.00 birr. A fixed service charge of 10 birr is added. Print the energy charge, the service charge and the total bill (two decimals). Use the conditional operator (no if).

Test data: 80 units gives energy 135.00 and total 145.00. 30 units gives energy 45.00 and total 55.00.

Task 3: Trip speed and fuel cost10 marks

Write a C++ program that reads the distance of a trip in km, the travel time as hours and minutes (whole numbers), the car’s fuel use in liters per 100 km and the price per liter (birr). Print the average speed (km/h), the fuel used (liters) and the fuel cost (birr), each with two decimals.

Test data: 150 km, 2 h 30 min, 8 L per 100 km, 60 birr per liter gives 60.00 km/h, 12.00 liters and 720.00 birr.
