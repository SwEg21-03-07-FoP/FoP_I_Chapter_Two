Problem Analysis and Coding Examples

The Method

Analyse the problem before you type code. Writing code is the last step. When you analyze and design first, the code almost writes itself. In short, folowing these steps makes writing code quick, because every line of code is already planned.

1 Problem description→2 Analysis: input and output→3 Process→4 Design→5 Write the code
  • Analysis: what goes in, and what must come out?
  • Process: the list of operations that turn input into output.
  • Design: decide the variables and their types, the constants, and the exact statements for reading, calculating and printing.
  • Code: type the design. Each design step becomes a block of code. Then test.

Example 1: A shop bill with discount and VAT

1. Problem description

Write a C++ program to calculate the amount a customer must pay in a shop. The program reads the unit price, the quantity bought and the discount rate (%). Orders of more than 10 items get an extra 5% discount. VAT of 15% is added after the discount.

Quantity Formula
subtotal unitPrice × quantity
discount subtotal × (discountRate + extra) / 100
taxable subtotal − discount
VAT taxable × 0.15
total due taxable + VAT

2. Problem analysis

2.1 Input
  • Unit price
  • Quantity bought
  • Discount rate (%)
2.2 Output
  • Subtotal, discount, VAT
  • Total due (the main result)

3. Process (operations)

  • Declare variables to hold the input and the results.
  • Define the fixed values (VAT rate, bulk limit, bulk extra discount) as constants.
  • Print a prompt and read the three inputs.
  • Decide the extra discount: 5% if the quantity is more than 10, otherwise 0.
  • Calculate subtotal, discount, taxable amount, VAT and total.
  • Print the results with two decimal places.

4. Design the program

4.1 Variables: what and how?

Variable Type Why this type
unitPrice double Prices have decimals.
quantity int You buy whole items.
discountRate double May be 7.5%.
extraRate double = 0.0 Starts at 0, changed only for bulk orders.
subtotal, discount, taxable, vat, total double Money results with decimals.

4.2 Constants

const double VAT_RATE = 0.15;
const int BULK_QTY = 10;
const double BULK_EXTRA = 5.0;

4.3 Reading the input

cout << "Enter unit price, quantity and discount rate (%) separated by space: ";
cin >> unitPrice >> quantity >> discountRate;

4.4 Calculation

subtotal  = unitPrice * quantity;
extraRate = (quantity > BULK_QTY) ? BULK_EXTRA : 0.0;
discount  = subtotal * (discountRate + extraRate) / 100;
taxable   = subtotal - discount;
vat       = taxable * VAT_RATE;
total     = taxable + vat;

4.5 Printing the result

Print the Total due along with Discount and VAT.

cout << fixed << setprecision(2);
cout << "Subtotal : " << subtotal << endl;
cout << "Discount : " << discount << endl;
cout << "VAT (15%): " << vat << endl;
cout << "Total due: " << total << endl;

5. Write the code

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    // Steps 4.1 and 4.2: constants and variables
    const double VAT_RATE = 0.15;
    const int BULK_QTY = 10;          // more than this counts as a bulk order
    const double BULK_EXTRA = 5.0;    // extra discount (%) for bulk orders
    double unitPrice, discountRate, extraRate = 0.0;
    double subtotal, discount, taxable, vat, total;
    int quantity;

    // Step 4.3: read the input
    cout << "Enter unit price, quantity and discount rate (%) separated by space: ";
    cin >> unitPrice >> quantity >> discountRate;

    // Step 4.4: calculate
    subtotal  = unitPrice * quantity;
    extraRate = (quantity > BULK_QTY) ? BULK_EXTRA : 0.0;
    discount  = subtotal * (discountRate + extraRate) / 100;
    taxable   = subtotal - discount;
    vat       = taxable * VAT_RATE;
    total     = taxable + vat;

    // Step 4.5: print the result
    cout << fixed << setprecision(2);
    cout << "Subtotal : " << subtotal << endl;
    cout << "Discount : " << discount << endl;
    cout << "VAT (15%): " << vat << endl;
    cout << "Total due: " << total << endl;
    return 0;
}

Sample run 1 (a bulk order):

Enter unit price, quantity and discount rate (%) separated by space: 100 12 10
Subtotal : 1200.00
Discount : 180.00
VAT (15%): 153.00
Total due: 1173.00

Sample run 2 (not a bulk order):

Enter unit price, quantity and discount rate (%) separated by space: 100 5 10
Subtotal : 500.00
Discount : 50.00
VAT (15%): 67.50
Total due: 517.50
Why these choices
  • The conditional operator ?: makes the “only if” decision without if. In Chapter 3 you can write the same thing with if.
  • The discount is a percentage, so divide by 100 once.
  • Constants are named, so a change in the VAT rate is made in one place.
  • Check by hand: 100 × 12 = 1200; 15% of it is 180; 1020 × 0.15 = 153; 1020 + 153 = 1173.

Example 2: Change from a cashier

1. Problem description

A cashier gives change using the fewest notes and coins of 100, 50, 10, 5 and 1 birr. Write a C++ program that reads the amount due and the amount paid (whole birr; the customer always pays enough), and prints the change and how many of each note or coin to give.

2. Problem analysis

2.1 Input
  • Amount due
  • Amount paid
2.2 Output
  • The change
  • Number of 100, 50, 10 and 5 birr notes, and 1 birr coins

3. Process (operations)

  • Declare integer variables (all amounts are whole birr).
  • Read the amount due and the amount paid.
  • Calculate the change as amount paid − amount due.
  • Determine the number of notes: Divide the change by each notes by keeping the reminder: rest ÷ value (integer division), and the new rest = rest % value.
  • Print the change and the five counts.

4. Design the program

4.1 Variables Definition

int amountDue, amountPaid; 		//Holds the two inputs, whole birr
int change; 				//Hold the change - amountPaid − amountDue.
int rest; 				//hold the reminder as we go diving the change by each notes.

int notes100, notes50, notes10, notes5, coins1; //hold the number of each note for the change.

4.2 Reading the input

cout << "Enter the amount due and the amount paid (whole birr): ";
cin >> amountDue >> amountPaid;

4.3 Calculation (/ counts, % leaves the rest)

change   = amountPaid - amountDue;
notes100 = change / 100;   rest = change % 100;
notes50  = rest / 50;      rest %= 50;
notes10  = rest / 10;      rest %= 10;
notes5   = rest / 5;       rest %= 5;
coins1   = rest;

Trace by hand for due 463, paid 1000 (change 537):

Step Count (rest ÷ value) Rest after
100 birr 537 / 100 = 5 537 % 100 = 37
50 birr 37 / 50 = 0 37 % 50 = 37
10 birr 37 / 10 = 3 37 % 10 = 7
5 birr 7 / 5 = 1 7 % 5 = 2
1 birr 2 0

4.4 Printing the result

Print the Change due and the number of each notes used for change.

cout << "Change: " << change << " birr" << endl;
cout << "100 birr notes: " << notes100 << endl;
cout << "50 birr notes : " << notes50 << endl;
cout << "10 birr notes : " << notes10 << endl;
cout << "5 birr notes  : " << notes5 << endl;
cout << "1 birr coins  : " << coins1 << endl;

5. Write the code

#include <iostream>
using namespace std;

int main() {
    // Step 4.1: variables
    int amountDue, amountPaid, change, rest;
    int notes100, notes50, notes10, notes5, coins1;

    // Step 4.2: read the input
    cout << "Enter the amount due and the amount paid (whole birr): ";
    cin >> amountDue >> amountPaid;

    // Step 4.3: calculate the change and the notes
    change   = amountPaid - amountDue;
    notes100 = change / 100;   rest = change % 100;
    notes50  = rest / 50;      rest %= 50;
    notes10  = rest / 10;      rest %= 10;
    notes5   = rest / 5;       rest %= 5;
    coins1   = rest;

    // Step 4.4: print the result
    cout << "Change: " << change << " birr" << endl;
    cout << "100 birr notes: " << notes100 << endl;
    cout << "50 birr notes : " << notes50 << endl;
    cout << "10 birr notes : " << notes10 << endl;
    cout << "5 birr notes  : " << notes5 << endl;
    cout << "1 birr coins  : " << coins1 << endl;
    return 0;
}

Sample run:

Enter the amount due and the amount paid (whole birr): 463 1000
Change: 537 birr
100 birr notes: 5
50 birr notes : 0
10 birr notes : 3
5 birr notes  : 1
1 birr coins  : 2
Why these choices
  • Everything is int. With double, % would not even compile, and decimals are not needed.
  • Integer division is the goal here: 537 / 100 must give 5, not 5.37.
  • Always go from the largest value to the smallest, so the fewest notes are used.
  • rest %= 50; is the compound form of rest = rest % 50;.

Example 3: Taxi fare

1. Problem description

Write a C++ program to calculate the fare of a taxi trip. The fare is a base fare plus a charge per kilometre plus a charge per minute of waiting. If the trip is longer than 20 km, the program asks for a surcharge per extra km and adds it for each kilometre beyond 20.
fare = base fare + distance × rate per km + waiting minutes × wait rate + surcharge

2.1 Input

  • total distance (km)
  • waiting time (minutes)

Constants

  • Base fare
  • rate per km
  • waiting rate
  • surcharge rate
  • long-trip limit

2.2 Output

  • the total distance
  • Waiting time
  • Extra distance
  • Base fare
  • Basic fare
  • Extra fare (extra distance & wiating time)
  • the total fare

3. Process / operation

  • Declare variables for the inputs and results.
  • Define the base fare, rate per km, wait rate and long-trip limit as constants.
  • Initialize the surcharge to zero.
  • Print prompts for user to input data
  • Read the input.
  • Check whether the distance exceeds 20 km.
  • Calculate the extra distance, Basic fare, Extra fare, Total Fare.
  • Print the result: total distance, waiting time, extra distance, Basic fare, Extra fare, Total Fare.

4. Design the program

4.1 Variable declaration and initialization

  • float distance, surchargeRate, surcharge = 0.0;
  • int waitMinutes;

4.2 Constant definition

  • const double BASE_FARE = 25.0, RATE_PER_KM = 12.0, WAIT_RATE = 2.0;
  • const double LONG_TRIP_KM = 20.0;

4.3 Reading input

  • cin >> distance >> waitMinutes;

4.4 Perform the operations

  • if (distance > LONG_TRIP_KM) { ...read surchargeRate...; surcharge = (distance - LONG_TRIP_KM) * surchargeRate; }
  • fare = BASE_FARE + distance * RATE_PER_KM + waitMinutes * WAIT_RATE + surcharge;

4.5 Print the result

Print the surcharge and the total fare with two decimals.

cout << fixed << setprecision(2);
cout << "Surcharge: " << surcharge << endl;
cout << "Total fare: " << fare << endl;

5. Write the code

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    // Step 3.1 and 3.2: declaration, initialization and constants
    const double BASE_FARE = 25.0, RATE_PER_KM = 12.0, WAIT_RATE = 2.0;
    const double LONG_TRIP_KM = 20.0;
    double distance, surchargeRate, surcharge = 0.0;
    int waitMinutes;

    // Step 3.3: read input
    cout << "Enter distance (km) and waiting time (minutes) separated by space: ";
    cin >> distance >> waitMinutes;

    // Step 3.4: calculate the fare
    if (distance > LONG_TRIP_KM) {
        cout << "Enter surcharge per extra km: ";
        cin >> surchargeRate;
        surcharge = (distance - LONG_TRIP_KM) * surchargeRate;
    }
    double fare = BASE_FARE + distance * RATE_PER_KM + waitMinutes * WAIT_RATE + surcharge;

    // Step 3.5: print the result
    cout << fixed << setprecision(2);
    cout << "Surcharge: " << surcharge << endl;
    cout << "Total fare: " << fare << endl;
    return 0;
}

Sample run (input in the first lines):

25 10
3
Surcharge: 15.00
Total fare: 360.00
Key ideas
  • Named constants make the formula readable and easy to change.
  • Check by hand: 25 + 25 × 12 + 10 × 2 + (25 − 20) × 3 = 25 + 300 + 20 + 15 = 360.

Quiz practical 1: Student result

Write a program that reads a student’s marks in five subjects (each out of 100). Print the total, the average and the word Pass if the average is 50 or more, otherwise Fail.

Test: 70 65 80 55 60 gives total 330.00, average 66.00, Pass.

Your analysis (input, output, process):Your code:
Model solution

2.1 Input

  • five marks

2.2 Output

  • total
  • average
  • Pass or Fail

3. Process / operation

  • Declare five variables for the marks (double, so decimals are allowed).
  • Define the pass mark (50) as a constant.
  • Read the five marks.
  • total = sum of the marks; average = total / 5.
  • Choose “Pass” or “Fail” by comparing the average with the pass mark. The conditional operator ?: does this in one expression.
  • Print the three results.

4. Design the program

Declarations and constants

  • double m1, m2, m3, m4, m5;
  • const double PASS_MARK = 50.0;

Operations

  • double total = m1 + m2 + m3 + m4 + m5;
  • double average = total / 5;
  • (average >= PASS_MARK ? "Pass" : "Fail")

5. Write the code

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const double PASS_MARK = 50.0;
    double m1, m2, m3, m4, m5;

    cout << "Enter five marks separated by space: ";
    cin >> m1 >> m2 >> m3 >> m4 >> m5;

    double total = m1 + m2 + m3 + m4 + m5;
    double average = total / 5;

    cout << fixed << setprecision(2);
    cout << "Total: " << total << endl;
    cout << "Average: " << average << endl;
    cout << "Result: " << (average >= PASS_MARK ? "Pass" : "Fail") << endl;
    return 0;
}

Sample run (input in the first lines):

70 65 80 55 60
Total: 330.00
Average: 66.00
Result: Pass
Key ideas
  • Because total is a double, total / 5 keeps the decimals. With int marks you would write total / 5.0.

Quiz practical 2: Painting a room

A room has four walls to paint. Read the room’s length, width and height (metres) and the paint cost per m². Doors and windows take up a fixed 5 m², which is not painted. One can of paint covers 10 m². Print the wall area to paint, the paint cost, and the number of cans needed (a part-used can still has to be bought).

Test: 5 4 3 10 gives area 49.00 m², cost 490.00 and 5 cans.

Your analysis (input, output, process):Your code:
Model solution

2.1 Input

  • length
  • width
  • height
  • paint cost per m²

2.2 Output

  • wall area to paint
  • paint cost
  • number of cans

3. Process / operation

  • Declare variables for the inputs.
  • Define the opening area (5) and can coverage (10) as constants.
  • Read the input.
  • wall area = 2 × (length + width) × height − openings.
  • cost = wall area × cost per m².
  • cans = wall area / 10, rounded up with ceil() from the math library.
  • Print the results.

4. Design the program

Declarations and constants

  • double length, width, height, ratePerM2;
  • const double OPENINGS = 5.0, CAN_COVERAGE = 10.0;
  • #include <cmath> for ceil

Operations

  • double wallArea = 2 * (length + width) * height - OPENINGS;
  • int cans = (int)ceil(wallArea / CAN_COVERAGE);

5. Write the code

#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    const double OPENINGS = 5.0;      // doors and windows (m2)
    const double CAN_COVERAGE = 10.0; // m2 covered by one can
    double length, width, height, ratePerM2;

    cout << "Enter length, width, height (m) and paint cost per m2: ";
    cin >> length >> width >> height >> ratePerM2;

    double wallArea = 2 * (length + width) * height - OPENINGS;
    double cost = wallArea * ratePerM2;
    int cans = (int)ceil(wallArea / CAN_COVERAGE);

    cout << fixed << setprecision(2);
    cout << "Wall area to paint: " << wallArea << " m2" << endl;
    cout << "Paint cost: " << cost << endl;
    cout << "Cans needed: " << cans << endl;
    return 0;
}

Sample run (input in the first lines):

5 4 3 10
Wall area to paint: 49.00 m2
Paint cost: 490.00
Cans needed: 5
Key ideas
  • 49 / 10 = 4.9, and ceil rounds up to 5. Plain integer division would give 4, which is too few cans.
  • The cast (int) converts the result of ceil (a double) into a whole number.

Quiz practical 3: Average speed

A runner covers a distance in a given time. Read the distance in km, then the time as hours, minutes and seconds. Print the total time in seconds and the average speed in km/h.

Test: 12 km in 1 h 30 min 0 s gives 5400 seconds and 8.00 km/h.

Your analysis (input, output, process):Your code:
Model solution

2.1 Input

  • distance (km)
  • hours
  • minutes
  • seconds

2.2 Output

  • total time in seconds
  • average speed in km/h

3. Process / operation

  • Declare a double for the distance and ints for hours, minutes and seconds.
  • Read the input.
  • total seconds = hours × 3600 + minutes × 60 + seconds.
  • time in hours = total seconds / 3600.0 (real division).
  • speed = distance / time in hours.
  • Print the results.

4. Design the program

Declarations

  • double distance;
  • int hours, minutes, seconds;

Operations

  • int totalSeconds = hours * 3600 + minutes * 60 + seconds;
  • double totalHours = totalSeconds / 3600.0;
  • double speed = distance / totalHours;

5. Write the code

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double distance;
    int hours, minutes, seconds;

    cout << "Enter distance (km), then hours, minutes, seconds: ";
    cin >> distance >> hours >> minutes >> seconds;

    int totalSeconds = hours * 3600 + minutes * 60 + seconds;
    double totalHours = totalSeconds / 3600.0;
    double speed = distance / totalHours;

    cout << fixed << setprecision(2);
    cout << "Total time: " << totalSeconds << " seconds" << endl;
    cout << "Average speed: " << speed << " km/h" << endl;
    return 0;
}

Sample run (input in the first lines):

12 1 30 0
Total time: 5400 seconds
Average speed: 8.00 km/h
Key ideas
  • Writing 3600.0 forces real division. With 3600 the integer division would give 1 hour instead of 1.5.
